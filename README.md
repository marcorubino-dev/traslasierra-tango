# Traslasierra Tango

Bilingual static website exploring tango, culture and local experiences in Traslasierra, Córdoba, Argentina.

## Languages

- Spanish: `/`
- English: `/en/`

## Project status

This is an exploratory cultural project. Activities, collaborators, dates, availability and prices are not confirmed by this website. Visitors are invited to make an inquiry; an inquiry is not a booking.

## Contact configuration

The inquiry form prepares a WhatsApp message for the visitor to review and send. It does not submit messages automatically or store form data.

Before enabling the contact channel, set `whatsappNumber` in `assets/js/config.js` to the appropriate international number using digits only, without a plus sign, spaces or hyphens. Do not add credentials or private information to this public repository.

Until the number is configured, the form will explain that the contact channel is unavailable.

## Development

The site uses plain HTML, CSS and vanilla JavaScript. No build step or backend is required.

## Publishing

The site is intended for GitHub Pages from the `main` branch and repository root.

## Images and privacy

Some photographs are loaded from Unsplash. The site has no backend or external form provider. Review image attribution/licensing and local privacy requirements before commercial launch.
